# Твой личный нутрициолог

## Краткое описание

Приложение для мягкого сопровождения в питании: без давления, жёсткого контроля и чувства вины. Цифровое продолжение формата работы с нутрициологом — опора на привычки, ритм и понятный план.

## Для кого

- для клиентов нутрициолога
- для людей, которым нужен понятный план питания
- для тех, кто часто срывается, устаёт, пропускает еду или теряет ритм
- для тех, кому важна поддержка, а не трекер

## Что умеет приложение

- старт программы на 7 / 14 / 30 дней
- персональный 7 / 14 / 30-дневный план питания на основе анкеты
- анкета пользователя
- сборка персональной программы
- учёт пищевых ограничений: глютен, лактоза, яйца, орехи, мясо, рыба, морепродукты
- безопасная пересборка плана при изменении анкеты или ограничений
- локальное кэширование персональной программы без повторной пересборки при обычном входе
- план питания
- экран дня
- AI-чат с Олесей для ежедневных вопросов по питанию, самочувствию и программе
- отметка выполненного дня
- мягкие live-подсказки при срыве, усталости, пропуске еды, сладком
- прогресс на основе `nutrition.dailyActuals`
- блок «Где мы сейчас»
- календарь без давления и слова «пропущен»
- локальная работа через `localStorage`
- базовая работа без интернета; AI-слой используется как дополнительное усиление
- онлайн/офлайн статус
- десктопная сборка через Tauri

## Главный принцип

«Олеся рядом» — ощущение живого сопровождения, а не отчёта перед системой. Без давления и без чувства вины: помочь продолжить, а не зафиксировать провал.

Пользователь может не только отмечать дни, но и обращаться в AI-чат с вопросами: что делать после срыва, как вернуться в ритм, чем заменить блюдо, как понять самочувствие и как продолжить без давления.

## Технологии

Tauri, React, TypeScript, Tailwind CSS, localStorage, Rust toolchain для desktop-сборки.

## Архитектура данных

- `nutrition.clientQuestionnaire` — сохранённая анкета клиента
- `nutrition.personalProgram` — сохранённая персональная программа питания и сопровождения
- сохранённая программа проверяется на соответствие текущей анкете и ограничениям перед повторным использованием
- при изменении анкеты или несовместимости ограничений программа пересобирается
- `nutrition.dailyActuals` — источник истины для факта выполненных дней
- `completedAt` — дата завершения дня
- `startedAt` — начало программы
- паузы вычисляются, но не сохраняются

## Как запустить тестовую сборку

Готовые файлы доступны в GitHub Releases:

- [Скачать Windows-установщик](https://github.com/imidg1825/nutrition-coach-desktop/releases/download/v0.1.0/nutrition.exe)
- [Скачать macOS-сборку Apple Silicon](https://github.com/imidg1825/nutrition-coach-desktop/releases/download/v0.1.0/macos-bundle.2.zip)
- [Скачать Android APK](https://github.com/imidg1825/nutrition-coach-desktop/releases/download/v0.1.0/nutrition-android-test.apk)

Важно:

— Windows: скачайте `nutrition.exe` и запустите установщик.

— macOS: скачайте `macos-bundle.2.zip`, распакуйте архив, откройте папку `dmg` и запустите `.dmg`.

Android:

[Скачать Android APK](https://github.com/imidg1825/nutrition-coach-desktop/releases/download/v0.1.0/nutrition-android-test.apk)

Инструкция:

скачайте файл `nutrition-android-test.apk` на телефон и откройте его.

Если Android покажет предупреждение «установка из неизвестных источников», разрешите установку для браузера или файлового менеджера.

Это тестовая сборка, не из Google Play.

Для локальной проверки после сборки у себя на машине:

1. Откройте папку:
   `src-tauri/target/release/bundle/nsis/`

2. Запустите установщик:
   `nutrition-desktop-app_0.1.0_x64-setup.exe`

Перед публикацией в Release установщики можно временно складывать в локальную папку `release-share/` — это только для организации файлов у разработчика, не источник загрузок для пользователей.

Windows может показать предупреждение, потому что приложение пока без цифровой подписи. На macOS при предупреждении о неизвестном разработчике попробуйте правой кнопкой по приложению → «Открыть».

## Ограничения

- не диагнозы
- не лечение
- не замена врачу
- программа учитывает пищевые ограничения, но не составляет лечебный рацион
- при множественных ограничениях пользователю рекомендуется согласовать питание со специалистом
- AI-чат не ставит диагнозы и не назначает лечение
- AI является дополнительным слоем и не обязателен для базовой работы приложения
- рекомендации носят информационный и поддерживающий характер

## Статус

R1: персональная программа питания, ограничения, локальное сохранение прогресса и базовое сопровождение реализованы. Перед публичным релизом остаются UX-polish strict-меню, constraint-aware вспомогательные тексты и финальное тестирование сборок.
